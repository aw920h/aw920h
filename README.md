# Hi, I'm <img src="./name.svg" alt="J" height="60" valign="bottom"/>

I am a Civil Engineering undergrad student, experimenting with technology to solve physical infrastructure and environmental problems. 

Traditionally, civil engineering relies on deterministic models and localized data. I am interested in bridging that gap by bringing advanced and emerging technologies into the geo-environmental space. 

### What I'm currently working on

*   **Machine Learning in Geotechnics:** I am developing a Physics-Constrained Neural Network to predict soil shear strength. Enforced with custom loss functions that allows the neural network to obey actual geomechanical laws and output confidence intervals.
*   **Environmental Monitoring:** Using Google Earth Engine and multispectral/hyperspectral satellite data to track trace gas emissions and soil disturbances across massive earthworks. 
*   **AI & HPC:** I have compiled **flash attention 3 (fa3)** distributable wheels for the latest **CUDA & PyTorch** versions for **NVIDIA Hopper GPUs** (Linux x86_64). Check out [`flash-attn-3-wheels`](https://github.com/aw920h/flash-attn-3-wheels) repo.
